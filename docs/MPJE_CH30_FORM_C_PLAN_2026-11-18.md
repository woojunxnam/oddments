## 1. Scope and controlling decisions

Form C will contain 120 **new original items** in English. It will test unfamiliar applications of Massachusetts and applicable federal pharmacy law. It will remain outside ordinary fixed/random practice before the learner's first completed C attempt. Learning explanations and all four option rationales are released after that attempt.

The accompanying [120-slot matrix](MPJE_CH30_FORM_C_SLOTS_2026-11-18.json) records a tested decision, a legally decisive variation, at least three nearby existing IDs, the primary official competency, a source pack, a candidate format and a production batch for every slot. [Source packs](MPJE_CH30_FORM_C_SOURCE_PACKS_2026-11-18.json) consolidate repeated legal research. All source verification statuses start as `pending`.

This plan applies to the separate full-length Form C. It does not inherit the old five-question template of 1/2/1/1 Areas or exactly 3 SBA/2 SATA per set. Existing Sets 1–48 and the general learning-mode rules remain historical learning material. Any future Sets 49–72 are learning presentations of C after first-attempt release, not a five-item repeating exam pattern.

Plan IDs `C001`–`C120` are editorial slots, **not exam delivery order**. Candidate permanent IDs are E30-241–360 only while the newest main still ends at E30-240; check collisions immediately before assigning permanent IDs. Retain each slot ID if an unverified candidate is replaced.

### Date gate

The default is the official **pre-March 1, 2027** MPJE Competency Statements. They allocate 22% / 33% / 24% / 21% to Licensure/Personnel, Pharmacist Practice, Dispensing Requirements and Pharmacy Operations. Our 26/40/29/25 is a rounded 120-item learning-form design, not a claim about the real allocation of 20 unscored items.

For an exam on or after March 1, 2027, stop the legacy-blueprint freeze and remap the actual decisions to the new four-domain content outline. Do not rename the old numeric Areas. The new 30/30/20/20 outline would suggest 36/36/24/24 for a 120-item educational form, subject to real competency remapping.

Official references: [current competencies](https://nabp.pharmacy/programs/examinations/mpje/competency-statements/), [2027 change](https://nabp.pharmacy/news/blog/mpje-content-outline/), [Candidate Bulletin](https://read.nxtbook.com/nabp/bulletin/naplex_mpje_bulletin/what_is_the_mpje.html).

## 2. What the new form must improve

The November 18 audit found 109/144 existing SBA items have a uniquely longest correct option by character count. The first 215-item portion contributes 105/129, versus 4/15 in the latest 25 items. Rule-bearing topic titles also appear before submission. These are item-writing and presentation signals, not proof that the underlying legal answers are wrong.

The immediate UI change removes topic/Area hints in active mocks and shows individual topic titles in ordinary practice only after checking. A/B source content, signatures and historical results are not rewritten by that presentation change.

Keep A/B as learning and retention material. Their remaining distractor/Area-remapping work can run as a separate maintenance stream; do not repeatedly re-audit all 240 before allowing C source planning to advance. Do not interpret an unchanged A/B raw score as calibrated readiness. Any later A/B content revision must regenerate its reviewed signature/manifest and preserve old-version results safely.

The latest 25 already added liability, language access, office-stock, samples, ward stock, refill consent, workplace delivery, continuity supply and downtime. Do not label these absent. New versions must change the legal decision, setting, actor, exception, evidence or clock, rather than only a drug name/date.

## 4. Efficient execution: research once, verify every claim

### Stage A — establish reusable source packs

Use the 11 source packs as independent research workstreams. Read existing cited primary sources first, check amendments/supersession and effective dates, and resolve the specific open legal forks required by the slots. Previous citations are leads, not fresh verification.

For each material rule record: exact section, official URL, accessed date, effective date, jurisdiction, covered setting/actor, conditions, exceptions and supporting passage location. Distinguish binding law, Board policy, agency guidance and publisher commentary. A source packet may support many questions; each item's options must still map to the actual rule and its conditions.

Avoid repeating the entire 2022–2026 anecdote search for every batch. Use the November 18 synthesis as editorial context. A new search is warranted only for a concrete missing experience signal or a material recent change. Public experiences inform realism, never a keyed legal answer or an invented topic frequency.

### Stage B — eight-item calibration pilot inside B1

Select two pilot slots per Area from B1. Favor the major gaps: role-specific workflow, whole-prescription decision, competing dispensing rules, and actual compounding/operations. These **eight count toward the 120**, not an extra set.

The initial pilot is **C002, C009, C035, C041, C067, C082, C099 and C118**: supervision during a workflow change, qualifying staffing composition, electronic-prescriber identity, offer/refusal documentation, emergency-origin partial dispensing, transferred packaging waiver, aseptic-competency evidence and FDA TE-table interpretation. Each is a candidate pending source verification; replace a blocked pilot within the same Area before authoring.

An author creates the stem, four choices and rationales. A separate reviewer receives the stem/choices and source packet **without the intended answer key**. Resolve disagreement from primary sources. Review specificity, reading burden, plausible distractors, ambiguity and whether the nearest existing items already answer the same decision.

After the pilot's style and verification method work, finish B1's remaining 22; then B2, B3 and B4. Do not produce 120 unreviewed drafts and postpone all corrections to the end.

### Stage C — 30-item rolling acceptance

Each batch has one structured item ledger. Review all four options, not just the intended correct answer. Keep authors and independent solvers separate for their own items. Reuse source work already checked in the same legal version; re-open a source when facts, scope, dates or conflicts require it.

Replace a legally ambiguous or cosmetic-duplicate candidate within its Area instead of forcing a rare exception into the bank. Preserve the abandoned candidate and reason in the ledger. Do not carry an unresolved answer-key issue into the next release merely to meet the item count.

### Stage D — full-form review and integration

Check the complete form for coverage, semantic duplication, presentation cues, repeated answer patterns, excessive reading burden and sequence leakage. Use automated checks for counts, IDs, required fields, exact duplicates, lengths and patterns; use human-style legal/editorial reasoning for defensibility and practical relevance. An automatic similarity score is a screening tool, not a novelty verdict.

All new items need source/choice approval once and independent solution review once. Re-review changed or disputed claims, rather than restarting a full legal review after every formatting edit. A legal or key change reopens the affected item; typography alone does not reopen all source packs.

## 5. Item acceptance contract

Each accepted item must have:

1. One clear primary decision with a valid primary competency; secondary tags if helpful.
2. A legally decisive difference from at least three nearby existing items, or an explicitly justified transfer check of a core rule in unfamiliar conditions.
3. Current Massachusetts/federal authority, effective-date handling and all necessary scenario conditions.
4. Four A–D options with a uniquely defensible SBA key or an exact defensible SATA key; every option has a separately verified rationale.
5. A blind-solver result and documented resolution of any alternative defensible answer.
6. No answer-bearing topic title before submission; no correct-only precision, padded correct answer or disposable extreme-word distractor.
7. Beginner-friendly post-exam explanations identifying the decisive fact and explaining what fact change could change the answer.
8. Original wording. Public topic reports and public publisher samples may inform design; protected exam recollections and private exam keys do not supply content.

Format and cognitive labels in the slot matrix are candidates. Retain four choices for compatibility. Select SBA or SATA according to the legal task; do not claim a true-exam ratio or force 3/2 in every five questions. A provisional style budget is about 24 concise recognition, 72 applied-workflow and 24 integrated items. Review actual assignments after the pilot; this is an editorial target, not measured exam frequency, and no item should be mislabeled to reach it.

Longer is not inherently harder or better. Use brief prescriptions, profiles, staff schedules, inventory logs and FDA TE-code tables where the document is the evidence needed to make a decision. Do not add irrelevant narrative or arbitrary tricky wording.

### Legal source limits and HOLD handling

The previous audit did not directly authenticate the entire subscription USP–NF text for ten older USP questions. Do not silently inherit a claim of complete primary-text verification. For C, verify the needed normative provision, or narrow the item to a proposition fully supported by the available controlling MA material/official source. If neither is possible, mark the candidate `HOLD` and replace it. Policy-versus-regulation conflicts must be resolved or avoided through an explicit, defensible scope; an anecdote or another AI's confidence is not a resolution.

Statuses: `planned` → `source_ready` → `drafted` → `blind_solved` → `legal_checked` → `editorial_pass` → `frozen`. `HOLD` is an exception status with a reason and replacement owner. The state machine is a workflow plan; none of these slots is `source_ready` today.

## 6. Technical integration: protect A/B and keep C unfamiliar

**Do not append 120 items to `questions.js` under the current runner.** `validateBank()` currently requires exactly 240 questions and the A/B manifest fingerprints that whole array. A direct append would make A/B unavailable.

Use a separate Chapter 30 C pool and manifest (planned names `form-c-questions.js` and `form-c-manifest.js`). Keep the current A/B pool and `mock-forms.js` intact. Add C through an adapter that resolves a form's pool, version, signature, 120-ID order and scoring rules. Do not weaken validation by replacing 240 with 360 while still checking a single shared signature.

Before enabling C, explicitly verify:

- A/B still resolve the same 240 objects and their original form assignments.
- Each form validates only its own approved pool/manifest and exactly 120 unique IDs.
- New C IDs do not collide with A/B; C ordering is frozen and not grouped by slot Area.
- Old A/B attempts, exports, drafts, bookmarks and results survive the adapter change. Use version-aware migration and per-form signatures; never reset all storage to make a migration pass.
- No C script enters the ordinary `index.html` fixed/random pool before the first completed C attempt. Do not accidentally load all 360 into an existing random selector.
- During the first C attempt, show one question, four choices, item type, progress and the continuous 150-minute timer. No topic/Area/answer/explanation hints, no skipped answer or backtracking.
- After completion, unlock C's own review and optional C learning sets. Keep C exposure tracking distinct from the 240-item practice pool; record that viewing outside this browser cannot be detected.
- Final C result includes form version, source-review date, first-attempt/retake distinction, time, raw score and primary-area scores. Optional uncertainty tracking may help review but is not a release blocker.

This is a public static repository. Post-exam reveal and not mixing C into practice are learning-exposure controls, not secure storage or proctoring. Repository readers can inspect published source. Never describe C as technically secret or verified unseen across devices.

A/B distractor rewrites are a separate content-version release. Combining them with the C-loader migration would make regressions and old-score interpretation unnecessarily difficult.
