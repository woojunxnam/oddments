## 이번 통합

- 질문: MA-CASE-0601–0640, MA-CASE-0641–0680. 정답은 YES 80,
  법규 KEEP 80, 현실성 FAIL 80이다. 실제 지문·보기의 단서와 가까운 문항을
  개별 비교한 근거를 보존하며 단순한 숫자·반복만으로 실패 처리하지 않았다.
- 기본 연습에서 새로 제외한 독립 감사 문항은 0607·0617·0626·0631·0645·0650·0662다.
- 후속 wave의 원문·모든 보기를 root가 직접 읽고 정답을 노출하는 문구를
  발견한 0713·0722·0736·0741·0748·0764·0767·0781·0785·0802·0826도
  편집 보류했다. 이 11개는 법규·정답 검증 NOT_ASSESSED, 새 저자 검토 수와
  독립 감사 credit 0이다. 실제 인용 문구·원 질문 hash에 결박된 보고서를
  보존한다. 후속 독립 감사는 원래 입력으로 계속한다.
- 기본 제외는 원래355개 중 127개와 MA-REV 별도 3개, 합계 130개다.
  기본 목록은 318개다. 보류를 실제 재작성으로 세지 않는다.
- 기존 개별 저자 검토의 미해결 보완 187개를 아카이브 경고에 연결했다.
  원래 blocker·모든 보기의 개별 검토 기록·현재 hash에 결박하고 새 검토
  또는 법적 오답 판정으로 확대하지 않는다.
- 노트 job5–8: w1-b-10/11/12, w1-c-1–8, w4-a-21,
  w2-a-2–8/10. 새 20절·615명제를 독립 감사했다. 개업 기한과 면허 유효기간,
  복귀 inventory 서명, codeine 조성·인용, buprenorphine 제품별 경로와
  낮은 schedule의 일반 의무에 대한 누락·범위를 구분해 기록했다.
- HIV/STI 처방의 통합 법령 페이지와 enacted Acts2025 Chapter14 §39의
  차이는 실제 개정법·시행 근거·후속 검색 범위를 직접 읽은 증거로 설명한다.
  검색 결과의 부재를 모든 후속 개정이 없다는 증명으로 바꾸지 않는다.
- 노트 본문·의미 M은 그대로다. 새로운 13번째 migration은 PR188
  Markdown/build snapshot과 원래 12개 manifest를 보존하고 이번 감사 표시만
  허용한다. 누락·법규 보류는 reader/다운로드/연결 카드에 표시하고 자동 일일
  복습에서 제외한다.

## 재개와 다음 배치

Root controller는 `/workspace/oddments`다. Worker는 각 별도 worktree/branch에서
증거만 쓴다. 큐와 생성물은 root만 순차 갱신한다. 상태를 커밋한 뒤 builder를
실행한다. 미커밋 상태·증거는 공개 집계가 거부한다. QA는 별도 고정 worktree에서
수행하여 진행 중인 lease 갱신과 섞지 않는다.

질문 job13–16은 권위 원장에서 자동 선정한 MA-CASE-0681–0840,
40개씩 G/H/C/F에게 배정했다. 노트 job9–12도 다음 20절을 자동 선정했고
B/E는 각각 oral-followup·w2-b-1–4와 w2-b-5–9의 5절씩 검토 중이다.
나머지는 큐에 대기한다. 같은 실제 세션을 새 auditor instance로 부풀리지 않는다.

기존 author 큐는 52개 통합 job이다. 독립 질문 큐는 12개, 독립 노트 큐는
8개가 통합됐다. 새 제출이 없는 QUEUED/LEASED/SUBMITTED job은 검토 수에
포함하지 않는다. `legacy_independent_metadata`는 통합된 후속 보고서를 자동
발견하므로 새 파일명을 매번 builder에 추가하지 않는다.

Worker의 원래 commit은 별도 `checkpoints/mpje-audit-workers-20261103`
브랜치와 worker-history-checkpoint.json으로 GitHub에서 보존한다. 얕은 CI의
읽기 전용 공개 소비자는 과거 worker Git 객체 없이 현재 커밋된 바이트·원문
binding·통합 event를 검증한다. Controller의 원래 worker commit/branch 검사는
그대로다. 기존 branch가 있으면 다른 HEAD로 덮어쓰지 않는다.

누락 보완을 위한 append-only census 재감사 구현은 별도 engineering branch
`mission/note-census-reassessment`의 bb4fee70072ff6faa438dd69e80b2dd769c3c7a5에
있고 아직 이 PR에 통합하지 않았다. 실제 수정 census와 새 독립 감사는 별도
작업이다. 기존 부정 판정을 다른 KEEP로 덮거나 원래 census·보고서·본문을
조용히 수정하지 않는다.

전체 2346개 원 질문 객체와 기존 12개 보호 migration는 PR182/PR188과
동일함을 직접 대조했다. 물리 기기 검증은 NOT RUN이다. Canonical 상태·rules·
schemas·4개 정책 및 기존 사용자 풀이·북마크 이력은 변경하지 않는다.
