## Authoring decision audit

- **Exactly 15** new question objects, consecutive E30-191 to E30-205 and five in each of Sets 39–41.
- Each set: 1/2/1/1 legacy Area distribution; 3 single-best answer + 2 SATA; four A–D options; **every choice has an individually keyed Correct/Incorrect rationale**. The 60 rationale-key prefixes, official source fields, dates, ID uniqueness and normalized-stem uniqueness were checked by executable code before GitHub write.
- Existing 190 question objects are parsed and preserved in original order and values; no quiz engine, bookmark, score, history or random sampling code edited.
- **E30-193 editorial adjustment:** existing E30-072 already asks if gonorrhea qualifies as chlamydia-only EPT; an isolated repeat would be weak. This new item tests the 2026 **independent gonorrhea treatment for an evaluated patient** versus the distinct EPT pathway for an unexamined partner. This is not a new blanket gonorrhea EPT authority.
- **E30-202 dates:** FDA notice issued August 6, 2026. Its earlier small-dispenser relief remains applicable through November 27, 2026, while the published extension covers selected provisions from November 27, 2026 through November 27, 2027. It expressly does not exempt other §582 obligations, including initial suspect-product quarantine; verify dates before reusing the question.
- **E30-194 date:** M.G.L. c.94C §21 was amended effective January 1, 2026. This case only tests the unchanged baseline initial-label requirement, avoiding an unsupported inference about federal preemption of the new reproductive-health practice-name exception.
- **E30-199 wording:** archived §III(A) of Joint Policy 2018-01 distinguishes ADDING a missing patient address/DEA number without a prescriber call from changing a patient to another person or adding a prescriber signature (a new valid prescription is required). No blanket permission to change a drug or CII earliest-fill date.
- **E30-205:** FDA §503B registration by itself is not FDA approval, CGMP certification, or exemption from Massachusetts 247 CMR21.04 nonresident registration. The MA provisional registration option in 21.03 has different restrictions and is not asserted for an out-of-state facility.
