# Local Private Source Boundary

`local_private/` is gitignored and is not tracked. This example directory documents a boundary; it is not an ingestion pipeline and grants no permission.

- Do not store or process NDA-protected, recalled, leaked, Pre-MPJE, or other confidential exam material. It remains prohibited pipeline input in every location.
- Commercial material may be stored or processed only when its applicable license expressly permits the intended retention, AI processing, transformation, and use.
- Possession or purchase does not imply AI-processing or publication permission.
- Before any licensed source is processed, create an explicit local source-use decision. Unknown permission means `HOLD` and all permissions default to false.
- Never move raw private content, embeddings, close paraphrases, or derived question text into this public repository.
