이 폴더는 실제 C 세션의 비활성 w3-a-3 후보 감사 증거이다.

공식 HTML/PDF payload는 확보한 원바이트를 유지하며 source raw SHA와 직접 결박한다. 원 HTML의 공백을 정규화하지 않았다. 편의용 추출 TXT만 줄 끝 공백을 정리했다. 형식 검사는 원 HTML을 제외한 작성 파일에 적용하며 primary payload 무결성은 모든 원바이트 SHA로 별도 검증한다.

CURRENT root committed ledger를 inventory(ledger_raw=...)에 명시 전달한다. Root의 미커밋 generated ledger는 runtime 증거로 사용하지 않는다. 후보 body를 활성화하거나 source/census/queue/generated를 수정하지 않는다. 원011 HOLD와 역사적 보고서는 보존한다.
