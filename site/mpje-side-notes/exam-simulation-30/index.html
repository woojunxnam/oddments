How the practice works

Select exactly one answer for single-best-answer questions. For SATA cases, select every legally defensible answer and no extra choices. The answer key and option-by-option explanations are hidden until you submit all five questions in a set. Each set is scored separately; SATA requires an exact match for credit.

These original questions simulate legal reasoning difficulty, exceptions, multiple authorities, and nearby distractors. The difficulty has not been psychometrically calibrated against secure NABP questions, and no candidate recollections have been copied into this collection.

Your answers are saved locally in this browser when storage is available. Use the "Retake this set" button to clear that set only.

Exam preparation: Before relying on any rule, check its effective date and the linked source. Massachusetts Board policies, enacted regulations, federal rules, and USP standards are not interchangeable. Some topics have unresolved interpretive tensions; this is an author-reviewed learning set, not an independently audited canonical examination bank.
